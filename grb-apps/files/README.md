# APK files

Upload file APK ke folder ini di server dengan nama persis seperti berikut
(sesuai konfigurasi `APK_URLS` di `grb-apps/index.html`):

- `jejak-kamera.apk`
- `my-cashflow-plus.apk`

File ini (`README.md`) hanya placeholder supaya folder `files/` ikut tersimpan
di git — boleh dihapus di server produksi setelah APK diunggah.
